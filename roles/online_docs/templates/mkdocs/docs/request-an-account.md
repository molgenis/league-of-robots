# Request an account via mail


## Instructions

**Copy the template mail below and fill in all the fields** (the yes/no field should be answered with either yes OR no).
If everything is filled in, please send it back to the [HPC helpdesk](../contact/) and request access of the group owners (preferably in the same email by cc'ing (all) the group owner(s).

**NOTE**

 - Make sure you include all group owners in the CC of the request - it will be approved only after the group owners approve your access to their own group(s)
 - All of the fields are mandatory for the account creation, failing to provide any of them will result in the account not being created
 - End date is valid if it is requested/confirmed by the group owner (or department's secretary) by sending the email directly to the [HPC helpdesk](../contact/)
 - Please read the [Code of Conduct](../coc_umcg_research_clusters/)

## Template email (copy everything)

```
Dear groupowner and helpdesk,

@the groupowners can you approve my access to your group by replying to this email.

I would like to request an account to the cluster.
 - First Name: 
 - Last Name:  
 - Email address: 
 - Public key: 
 - End date contract (YYYY-MM-DD):
 - Groups to access:
   - 
 - I have read, understood and I agree to the UMCG HPC Code of Conduct:	yes/no

Best regards,
[NAME]
```
